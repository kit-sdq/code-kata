<!-- de -->
**Praxisaufgabe – am eigenen Rechner ausführen.**

Verwenden Sie die bereits übersetzte Datei `Hallo.class` aus der vorherigen Aufgabe (falls Sie sie nicht mehr haben: legen Sie `Hallo.java` erneut an und übersetzen Sie sie mit `javac Hallo.java`).

Führen Sie das Programm im selben Ordner aus mit:

```
java Hallo
```

Was gibt das Programm im Terminal aus? Geben Sie den Text genau so an, wie er erscheint.

<!-- en -->
**Hands-on task – run this on your own machine.**

Use the already-compiled `Hallo.class` file from the previous exercise (if you no longer have it: create `Hallo.java` again and compile it with `javac Hallo.java`).

Run the program in the same folder with:

```
java Hallo
```

What does the program print in the terminal? Give the text exactly as it appears.
