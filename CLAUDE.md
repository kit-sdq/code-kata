# code-kata — Project Instructions

## Language: English for all text on GitLab

All new text that goes to GitLab is written in English, so that colleagues who
read only English can follow it. This covers READMEs, `CLAUDE.md` files, review
notes, state files, logs, wiki pages, commit messages, issues and merge-request
descriptions. Material written for students stays German: slides, speaker
notes, video narration, Lesefassungen, exercise sheets, katas, and a glossary
of German course terms. Quotes from German material stay German, with a short
English gloss where the meaning is not obvious. Translate an existing German
file when it is next shared or substantially reworked, and ask before
translating a very large one.
